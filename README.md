# LangCards — Платформа для изучения языков по карточкам

Веб-приложение на **Python (Django)** и **SQLite** для изучения иностранных слов с помощью карточек и отслеживания статистики прогресса.

## Стек технологий
- **Backend**: Python 3, Django (Django ORM, стандартная система аутентификации `django.contrib.auth`)
- **База данных**: SQLite (`db.sqlite3`)
- **Frontend**: Django Templates, HTML5, CSS3, Bootstrap 5 (через CDN), поддержка светлой и тёмной темы

## Архитектура моделей (`cards/models.py`)
1. **`Deck` (Языковая колода)**:
   - `title` — название колоды (например, «Английский: A1 Базовый»)
   - `source_language` — исходный язык
   - `target_language` — изучаемый язык / язык перевода
   - `owner` — связь с пользователем (`ForeignKey` к `User`)
2. **`Card` (Карточка со статистикой прогресса)**:
   - `deck` — связь с колодой (`ForeignKey` к `Deck`)
   - `front_text` — исходное слово или фраза
   - `back_text` — перевод или толкование
   - `example` — опциональный контекстный пример
   - `review_count` — общее количество повторений
   - `success_count` — количество правильных ответов
   - `status` — статус освоения (`new` — Новое, `learning` — Изучается, `learned` — Выучено)
   - `last_reviewed_at` — дата и время последнего повторения

## Запуск проекта

Проще всего запустить через готовый файл `run.bat` или командой в терминале:

```powershell
.\.venv\Scripts\python.exe manage.py runserver
```

Откройте в браузере: `http://127.0.0.1:8000/`
